# Memoria

Memoria 是一个面向 Obsidian 的碎片笔记插件，用瀑布流卡片承载随手记录、待办、图片、链接和回顾统计。

核心原则很简单：插件负责快速输入和浏览体验，数据始终保存在你的 vault 里，格式是普通 Markdown。

当前版本：v2.0.3

## 适合什么场景

- 像浮墨、Blinko 那样随手记一条闪念。
- 把日常想法、链接、图片、待办统一沉淀到 Obsidian。
- 用时间线、标签、搜索和热力图回看长期记录。
- 不希望笔记被数据库或专有格式锁住。

## 主要功能

### 快速记录

- 主面板顶部输入框，支持 `Ctrl+Enter` / `Cmd+Enter` 发送。
- 命令面板提供快速记录弹窗，适合绑定全局快捷键。
- 输入框草稿会按 vault 写入本地缓存，未发送内容不容易丢。
- 支持从剪贴板、拖拽、文件选择插入图片，图片会保存到配置的附件目录。
- 支持粘贴 HTML 内容并尽量转换为 Markdown。
- 标签联想会读取 vault 中已有标签，支持层级标签。
- 工具栏可插入标签、图片、无序列表、有序列表、任务列表和表格。
- 时间芯片支持选择记录时间，编辑旧笔记时可连同时间一起修改。

### 浏览与筛选

- 按日期分组的瀑布流时间线。
- 侧栏展示笔记数、标签数、活跃天数、近期热力图或月历。
- 支持全部、置顶、收藏、今天、本周、待办、每日回顾、随机回顾等视图。
- 支持无标签、有图片、有链接等检索式。
- 支持按年份、日期、标签筛选。
- 支持保存当前筛选条件，并在侧栏一键复用。
- 支持宽松和紧凑两种视图密度，滚动到底自动加载更多。

### 卡片能力

- Markdown 由 Obsidian 原生渲染，代码块、表格、callout、任务列表都能保持主题一致。
- 宽表格自动横向滚动，不会撑破卡片。
- 图片按九宫格展示，点击进入大图浏览。
- 任务列表可以直接勾选，结果会回写到 Markdown 文件。
- 长笔记可按设置自动折叠，点击继续阅读展开。
- 双击卡片进入编辑模式，卡片菜单支持置顶、收藏、编辑、引用、打开原文、复制原文和删除。
- 卡片菜单支持将 memo 转为独立 Markdown 正式笔记，并保留来源时间和原始文件路径。
- 置顶、收藏通过 `#置顶`、`#收藏` 两个保留标签实现，因此在 Obsidian 标签系统里也可见。
- 可选开启情感色彩，根据关键词在卡片左侧显示情绪色条。

### 回收站

- 删除 memo 时默认写入 `_trash.md`。
- 提供独立回收站视图，可搜索已删除记录。
- 支持一键恢复到原日期。
- 支持永久删除单条记录或清空回收站，执行前会二次确认。

### 标签整理

- 提供独立标签整理视图。
- 可搜索标签并查看每个标签影响的 memo 数。
- 支持重命名标签；当目标标签已存在时，相当于合并标签。
- 支持移除某个标签及其子标签，执行前会确认影响范围。
- `#置顶` 和 `#收藏` 是保留标签，不参与批量整理。

### 数据报告

- 独立数据报告页。
- 总览笔记数、字数、活跃天数、时间跨度。
- 365 天活跃热力图，支持切换年份。
- 月度分布、24 小时活跃分布、Top 10 标签、标签云。
- 自动计算最长连续记录、最活跃日期、最长笔记等发现。

### 年度全景

- 独立年度全景页。
- 以 12 个月日历格展示全年记录密度。
- 支持切换上一年、下一年和回到今年。

### 导出

- 可导出当前筛选结果。
- 支持 Markdown、HTML、JSON 三种格式。
- 默认导出到 `Memoria/exports/`，该目录不会被 Memoria 当作普通笔记再次加载。

### 移动端

- 移动端使用抽屉式侧栏。
- 卡片操作按钮在移动端常显。
- 表格选择器、布局和触控区域做了移动端适配。

## 数据格式

默认情况下，Memoria 在 vault 的 `Memoria/` 文件夹下按年份维护 `YYYY.md` 文件。每条 memo 是一个时间行加缩进内容块：

```markdown
# 2026

## 2026-04-25 周六

- 12:43
  这是今天的第一条想法 #灵感

- 14:20
  又想到了一件事
  可以换行继续写，每一行缩进 2 个空格

- 15:47
  > [!tip] callout、任务列表、标题、表格和代码块都能渲染

- 16:30
  - [ ] 任务列表可以在卡片里勾选
  - [x] 勾选后会自动回写
```

文件组织示例：

```text
Memoria/
├── 2025.md
├── 2026.md
├── _trash.md
├── attachments/
│   └── memoria-20260425-124300-abcd.png
├── notes/
│   └── 2026-04-25-1243-一条正式笔记.md
└── exports/
    └── memoria-export-20260425-1250.md
```

说明：

- `YYYY.md` 是普通 Markdown 文件，停用插件后仍可直接阅读和编辑。
- `_trash.md` 用于保存被删除的 memo，文件名以下划线开头，不会进入主时间线。
- `notes/` 是 memo 转正式笔记的默认输出目录，可在设置中修改。
- `exports/` 用于保存导出结果，也不会进入主时间线。
- 图片保存在 vault 中，通过 Obsidian wikilink 引用。

## 搜索语法

搜索框既支持普通关键词，也支持简单查询语法：

| 写法 | 含义 |
| --- | --- |
| `灵感` | 内容包含“灵感” |
| `#项目` | 包含 `#项目` 或其子标签 |
| `-焦虑` | 排除包含“焦虑”的笔记 |
| `-#工作` | 排除 `#工作` 及其子标签 |
| `date:2026` | 限定 2026 年 |
| `date:2026-04` | 限定 2026 年 4 月 |
| `date:2026-04-25` | 限定某一天 |
| `after:2026-04-01` | 限定该日期之后 |
| `before:2026-04-30` | 限定该日期之前 |

可以组合使用，例如：

```text
#实验 after:2026-04-01 -失败
```

## 安装

### 手动安装

1. 在 vault 的插件目录中新建文件夹：

```text
<Your Vault>/.obsidian/plugins/memoria/
```

2. 将以下文件复制进去：

```text
main.js
manifest.json
styles.css
```

3. 在 Obsidian 中进入设置，关闭安全模式或启用第三方插件。
4. 重新加载已安装插件，启用 Memoria。
5. 点击左侧 Ribbon 的羽毛图标，或在命令面板中搜索 Memoria。

### 从源码构建

```bash
npm install
npm run build
```

构建产物会输出到项目根目录的 `main.js`。

开发监听：

```bash
npm run dev
```

## 命令

在 Obsidian 命令面板中搜索 Memoria 可找到：

| 命令 | 用途 |
| --- | --- |
| 打开 Memoria 面板 | 打开主时间线 |
| 打开数据报告 | 打开统计页 |
| 打开 Memoria 回收站 | 查看、恢复、永久删除已删除 memo |
| 打开 Memoria 标签整理 | 搜索、重命名、合并或移除标签 |
| 快速记录（弹窗） | 弹窗输入并保存一条 memo |
| 规范化所有笔记格式 | 将历史 memo 重写为当前缩进格式 |

注意：规范化会重写 Memoria 笔记文件，执行前建议先备份 `Memoria/` 文件夹。

## 设置

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 笔记文件夹 | `Memoria` | 读取和写入 `YYYY.md` 的位置 |
| 图片附件文件夹 | `Memoria/attachments` | 粘贴、拖拽、选择图片后的保存位置 |
| 正式笔记输出目录 | `Memoria/notes` | memo 转正式笔记时的默认保存目录 |
| 发送后清空输入框 | 开启 | 发送成功后清空输入框 |
| 每次加载条数 | `50` | 时间线懒加载批次大小 |
| 侧栏标签树 | 关闭 | 开启后在侧栏显示层级标签 |
| 删除时保留到回收站 | 开启 | 删除 memo 时写入 `_trash.md` |
| 回收站最大条数 | `300` | 超出后裁掉最旧删除记录 |
| 长笔记自动折叠 | `8` 行 | 超过阈值后折叠正文 |
| 每日目标笔记数 | `5` | 侧栏进度条的目标值 |
| 视图密度 | 宽松 | 可切换为紧凑 |
| 情感色彩可视化 | 关闭 | 根据关键词显示情绪色条 |
| 语言 | 自动 | 跟随 Obsidian，支持简体中文和英文 |

## 开发说明

- 入口文件是 `src/main.ts`。
- 构建工具是 esbuild，输出 CommonJS 格式的 `main.js`。
- TypeScript 目标为 ES2018。
- 运行 `npm run build` 会先执行 TypeScript 类型检查，再打包。
- 插件只依赖 Obsidian API 和构建期依赖，不引入运行时数据库。

## 数据主权

- 不使用 SQLite、IndexedDB 或专有同步格式保存 memo。
- 置顶和收藏是普通标签。
- 删除记录默认保存在普通 Markdown 回收站文件。
- 导出结果也是 vault 内文件。
- 任何时候停用 Memoria，原始笔记仍然是可读、可复制、可迁移的 Markdown。
